# 4IRC - Sécurité Web et Code

Cours de sécurité web et code.

La plateforme de challenge est disponible sur : https://dashbox.cloud/

## Keycloak (Docker)

Lancer Keycloak + PostgreSQL :

```bash
docker compose up -d
```

Accès à la console admin : http://localhost:8080 — identifiants `admin` / `admin`.

Arrêter les conteneurs :

```bash
docker compose down
```
